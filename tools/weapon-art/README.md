# XM8: утверждённый рисунок

Текущий внешний вид импортирован непосредственно из `reference/xm8-approved.png` — концепта «XM8 — REVISED», утверждённого пользователем. Исходный концепт сохранён целиком, включая фон презентации.

Воспроизводимый импорт (нужен Pillow):

```powershell
..\brainout\build\pyenv\Scripts\python.exe tools\weapon-art\import_xm8_concept.py
```

Запускать из корня `brainout-xm8`. Старый `xm8.py` сохранён как прежний процедурный вариант; его запуск перезапишет утверждённые текстуры старой отрисовкой.

Импорт удаляет связный фон, включая отверстия ручки и спусковой скобы, затем разделяет исходные пиксели на корпус, приклад и магазин. RGB непрозрачных пикселей не перерисовывается, текстуры не уменьшаются. Все детали используют единое преобразование координат: пропорции рисунка сохраняются. В игре размер задают прямоугольники вложений Spine, поэтому при игровом масштабе действует обычная фильтрация текстур.

Меняются только три `textures/GAME/xm8-*.png`, визуальные размеры/координаты вложений в `weapon-xm8.json` и его метаданные границ. У существующего глушителя `g36c-silencer` подправлено только вертикальное положение относительно нового дульного среза. Кости, слоты, дорожки и таблицы анимаций рук, характеристики, звуки и определения апгрейдов сохранены.

Глушитель уже был подключён через `upgrade-xm8-silencer` в `Store Item.txt`. Его существующие эффекты и изменение параметров при установке не переписаны.

Импорт проверяет побайтовое совпадение RGB видимых пикселей после обратной сборки деталей. Локальные результаты: `build/xm8-concept-import/` — прозрачная сборка, превью на светлом и тёмном фоне, координаты разрезания и SHA-256 исходника в `provenance.json`. Копия файлов до импорта находится в `build/xm8-before-concept-import/`.

После импорта нужно заново упаковать контент клиента и сервера через штатный `scripts/make_data.py`. JAR пересобирать не требуется. Для проверки используется `play-xm8-test.bat`.

Проверено 2026-11-07: клиент и сервер загружают новые пакеты; XM8 видна в руках персонажа и в меню модификаций с глушителем. Контрольные суммы `Weapon.txt`, `Animation.txt`, `Upgrades/Silencer.txt` совпадают с состоянием до импорта; кости, слоты и дорожки `weapon-xm8.json` также совпадают. Проверка не включает отдельный покадровый прогон всех движений перезарядки.

## Пиксельная версия для игры (текущая)

Большие текстуры из импорта игра сжимала в ~13 раз «по ближайшему пикселю» — в руках пушка выглядела рябой. Теперь в игре стоят версии в родном размере (1 пиксель текстуры = 1 единица игры, как у оригинального оружия): корпус 90×36, приклад 40×21, магазин 13×16.

```powershell
..\brainout\build\pyenv\Scripts\python.exe tools\weapon-art\pixelize_xm8.py
```

Берёт `reference/xm8-*-hires.png` (детали, вырезанные импортом), уменьшает усреднением, делает жёсткий край и общую палитру на 28 цветов, закрашивает смазанную надпись XM8 (правки — `FILL`/`FIXES` в скрипте) и записывает размеры вложений в `weapon-xm8.json`. Превью — `build/xm8-pixel/preview.png`. Порядок, если меняется концепт: `import_xm8_concept.py` → скопировать три текстуры в `reference/*-hires.png` → `pixelize_xm8.py` → `make_data.py client/server`.
