BRAIN / OUT — клиент для игры по сети (Radmin VPN / LAN)
==========================================================

Ничего ставить не нужно: Java уже лежит в папке jre.

1. Установите Radmin VPN и войдите в ту же сеть, что и хост.
2. Узнайте у хоста его IP в Radmin VPN (вида 26.x.x.x).

Есть два способа играть — смотря что запустил хост.

ОНЛАЙН (хост запустил play-online.bat) — как в старом Steam:
   хаб, рубли, тайник, барахолка, кланы, друзья.
   Запустите connect-online.bat, введите IP хоста и свой ник.
   Друзей добавляйте по нику: Esc в игре -> «Пригласить» или
   кнопка приглашения в отряд в хабе -> поле «Ник друга» -> «Добавить».
   Когда друг ответит тем же, вы друзья и можете звать друг друга в игру.

ПРОСТО МАТЧИ (хост запустил play-bots.bat, play-freeplay.bat и т.п.):
   Запустите connect.bat, введите IP хоста и своё имя.
   Здесь всё оружие сразу открыто, без рублей и хаба.

В обоих случаях IP и имя запоминаются: потом можно просто жать Enter.
Под ником хранится ваш прогресс — вводите тот же самый.

Если не подключается:
- хост должен уже запустить сервер;
- у хоста брандмауэр Windows должен разрешить Java и Python
  (онлайн: порт 9511 и 36600+; просто матчи: 36555-36557);
- версия игры должна совпадать с хостом: берите архив у него.

Если игра вылетает, пришлите хосту файл client-last.log из этой папки.
